# brazilian-companies-financial-analytics
End-to-end Financial Analytics and Business Intelligence project using Brazilian public companies' financial statements. Built with Python, SQL, Power BI and DAX, focusing on financial performance, profitability, liquidity, benchmarking and data governance.
Brazilian Public Companies | Financial Analytics & BI

# Project Overview

This project aims to develop an end-to-end Business Intelligence solution to analyze the financial performance of Brazilian publicly listed companies using official financial statements provided by the Brazilian Securities and Exchange Commission (CVM).

The solution integrates data extraction, transformation, validation, dimensional modeling, financial analysis and interactive data visualization.

# Business Objectives

Evaluate financial performance and year-over-year growth.
Analyze profitability, liquidity, solvency and cash flow.
Identify financial trends and potential risks.
Compare companies and industry benchmarks.
Support data-driven financial and strategic decision-making.
Ensure data accuracy, consistency and traceability.

# Data Source

Brazilian Securities and Exchange Commission (CVM) — Open Data Portal.

# Financial statements:

Balance Sheet — Assets (BPA)
Balance Sheet — Liabilities and Equity (BPP)
Income Statement (DRE)
Cash Flow Statement — Direct Method (DFC)

Data Architecture

# The project follows a layered data architecture:

Bronze: Raw data ingestion.
Silver: Data cleaning, standardization and validation.
Gold: Business rules and analytical data modeling.
Analytics: Power BI semantic model and dashboards.
